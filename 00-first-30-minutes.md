# Your first 30 minutes

The aim is one small success: make one visible, working change and save it for your team.

## 1. Start the project

1. Clone or open the team repository.
2. Read `brief.md`, `DESIGN.md` and `AGENTS.md`.
3. Follow the run command in `AGENTS.md`.
4. Open the local app URL and confirm it loads.

If it does not run, copy the complete terminal error and use the debugging guide before changing anything else.

## 2. Give Codex the project context

Paste this:

> Read `brief.md`, `DESIGN.md` and `AGENTS.md`. Tell me what the project is for, how to run it, and which screen is safest to change first. Do not write code yet.

Correct anything Codex misunderstood by editing the templates—not by hoping it remembers.

## 3. Make one small change

Choose one safe change: a heading, button label, card spacing or empty state. Show a screenshot if it must match a design.

> Change only [exact element] on [screen/route]. Follow `DESIGN.md`; do not change behaviour or unrelated files. It is done when [visible check]. Tell me what could break, then make the change.

Run the app and check it yourself.

## 4. Save the win

Create a branch, commit with a clear message, and open a PR. Example: `Improve idea-card spacing`.

A working, saved small change is the beginning of a prototype—not a trivial exercise.
